# Подключение модуля

## Файлы

Переносите папку целиком. `viewer.js` — публичный вход. `internal/`, `vendor/` и `assets/` — его локальные зависимости. `demo.html`, `demo.js` и `demo.css` показывают рабочее подключение и не нужны на вашей странице.

Разместите модуль как статические файлы на своём сайте. Сборка не требуется. Если используете сборщик, обеспечьте копирование зависимостей и сохраните их относительные пути; не переносите один `viewer.js` отдельно.

## Создание

```js
import { createPrintViewer } from './metal-print-viewer/viewer.js';

const viewer = await createPrintViewer(container, {
  image: '/photos/example.jpg',
  widthCm: 30,
  heightCm: 40,
  size: 'M',
  mount: 'float',
  finish: 'gloss',
  mode: 'front',
  backText: null,
  watermark: false,
  visible: true,
  onError(error) {
    // Покажите понятное сообщение пользователю.
    console.warn(error.code, error.message);
  },
});

await viewer.readyImage();
```

У `container` должны быть ненулевая ширина и высота, например `width:100%; height:500px; position:relative`. Размер canvas подстраивается под контейнер.

### Параметры

| Поле | Значения | Назначение |
| --- | --- | --- |
| `image` | URL строкой, `URL` или `null` | Фото; `null` убирает изображение. Для локального файла используйте `URL.createObjectURL(file)`. |
| `widthCm`, `heightCm` | Числа от 10 до 150 | Ширина и высота панели в сантиметрах. Для горизонтального вида поменяйте их местами. |
| `size` | `'M'`, `'L'`, `'XL'` | Вариант крепления: у XL их два. Сам размер задают `widthCm` и `heightCm`. |
| `mount` | `'float'`, `'magnet'`, `'standard'` | Обычное крепление, магнитное или настольная подставка. |
| `finish` | `'gloss'`, `'brushed'` | Глянец или шлифованный металл. |
| `mode` | `'front'`, `'back'` | Начальный ракурс или переход к выбранной стороне. |
| `backText` | `null` или объект ниже | Надпись на обратной стороне. |
| `watermark` | `false`, `true` или строка | Без водяного знака, `PREVIEW` или свой текст. |
| `visible` | `true`, `false` | Управляет работой просмотра, например при смене вкладки. |
| `spots` | `null`, `[]` или массив `{ x, y, t }` | Автоматические точки креплений, без точек или свои подписи. `x` и `y` — проценты от 0 до 100. |
| `onError` | Функция | Получает ошибку с `code` и `message`. |

Демо использует размеры M — 30 × 40, L — 45 × 60, XL — 60 × 80 см. Это примеры; размеры вашего продукта задавайте явно.

Фото заполняет панель по центру. Если пользователю нужен точный кадр, подготовьте изображение нужного соотношения сторон в своём редакторе до передачи в просмотр.

### Надпись на обороте

```js
viewer.update({
  mode: 'back',
  backText: {
    text: 'Сохрани этот момент',
    position: 'bottom-center',
    fontMm: 10,
  },
});
```

`fontMm` — физическая высота букв: 10, 30 или 50 мм. Для переноса старых данных также принимаются 4, 5, 6 и 8 мм.

Положение задаётся сочетанием `top`, `middle` или `bottom` с `left`, `center` или `right`: например, `top-left` или `middle-center`. Если текст не помещается или попадает на крепление, модуль отклонит настройки. Обработайте ошибку: предложите сократить текст, уменьшить буквы или поменять положение. Для удаления надписи передайте `backText: null`.

## Обновление и очистка

```js
// update синхронный. Передавайте только изменившиеся поля.
try {
  viewer.update({ widthCm: 40, heightCm: 30, mount: 'magnet' });
} catch (error) {
  // Некорректные размеры или несовместимое размещение надписи.
}

// Новое изображение загружается асинхронно.
viewer.update({ image: '/photos/next.jpg' });
try {
  await viewer.readyImage();
} catch (error) {
  // Не удалось загрузить или декодировать изображение.
}

// Метаданные состояния; не содержат файлы или токены.
const state = viewer.getState();
// state.imageStatus: empty | loading | ready | error | destroyed
// state.environment: loading | studio | fallback

// Перед удалением контейнера освободите события, canvas и ресурсы GPU.
viewer.destroy();
```

`update()` возвращает тот же объект просмотра. `readyImage()` ждёт последнее запрошенное изображение. `destroy()` можно безопасно вызвать повторно. Разрешено несколько независимых экземпляров на странице.

При работе с `blob:` URL храните адрес до завершения загрузки. Вызывайте `URL.revokeObjectURL()` при замене фото или закрытии компонента. Фото само по себе никуда не отправляется; загрузку и хранение файлов ваш проект организует отдельно.

## React и серверный рендеринг

Создавайте экземпляр после монтирования DOM, сохраняйте его в `ref` и уничтожайте в функции очистки эффекта. В Next.js и похожих проектах используйте клиентский компонент и динамический `import()` внутри эффекта. Не вызывайте `createPrintViewer` на сервере.

Если компонент успел закрыться, пока `createPrintViewer()` выполнялся, сразу вызовите `destroy()` у полученного экземпляра. При смене параметров используйте `update()`, вместо повторного создания сцены.

## Сеть и ограничения

- Все зависимости включены локально. Внешних CDN и обращения к API Metavista нет.
- На сервере нужны корректные MIME-типы для `.js`, `.webp` и `.svg`.
- Внешнее фото должно разрешать CORS; загрузка обычным `<img>` без CORS ещё не означает, что его можно использовать в WebGL.
- При строгой Content Security Policy разрешите локальные скрипты и изображения; если выбираете локальные файлы — также `blob:` для изображений. Политика вашего приложения может потребовать дополнительных разрешений для его собственных функций.
- При отсутствии WebGL создание просмотра отклоняется с `code: 'webgl_unavailable'`. Обработайте эту ошибку и покажите обычный `<img>`, как в `demo.js`. Материал, вращение, крепления и надпись на обороте в таком режиме не воспроизводятся.
- Освещение при ошибке загрузки заменяется резервным. Режим виден в `getState().environment`.
- Это продуктовый предпросмотр металлической панели. Редактор кадра, улучшение фотографий, экспорт печатного файла и работа с произвольными 3D-моделями в комплект не входят.

## Задание для другого агента

Скопируйте этот текст вместе с путём к папке модуля:

> Подключи готовый модуль `metal-print-viewer` к моему проекту. Сначала прочитай `README.md` и `INTEGRATE.md`, затем посмотри рабочий пример `demo.js`. Используй публичный API `createPrintViewer` из `viewer.js`. Перенеси локальные зависимости с сохранением относительных путей. Добавь контейнер с высотой и передавай выбранное пользователем фото, физические размеры, крепление и поверхность. Настрой понятную ошибку загрузки и освобождение ресурсов через `destroy()` при закрытии компонента. В проекте с серверным рендерингом запускай модуль только в браузере. Сохрани самостоятельность модуля: подключение к магазину и серверу Metavista не требуется. Проверь своё фото, смену параметров, мобильный экран и повторное открытие просмотра.
