# 3D-просмотр печати на металле

Готовый отдельный модуль из проекта Metavista. Его можно скопировать в другой сайт: магазин, админка и сервер Metavista ему не нужны.

Что переносится:

- Вращение и масштабирование панели мышью и касанием.
- Тонкий металлический лист, блики и два варианта поверхности.
- Лицевая и обратная сторона, обычное и магнитное крепления.
- Физические размеры и два крепления у XL.
- Надпись на обороте с проверкой свободного места.

Это просмотр печати на прямоугольной панели. Загрузки произвольных моделей `.glb`/`.gltf`, редактора фотографий и функции улучшения качества здесь нет.

## Открыть демо

Нужен Python 3. Из этой папки запустите:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:8080/demo.html](http://127.0.0.1:8080/demo.html). Через двойной клик по HTML модули не запустятся: нужен HTTP-сервер.

В демо можно выбрать своё фото. Оно открывается локально в браузере и никуда не отправляется. Пример `assets/demo.svg` нарисован специально для этого комплекта; чужих фотографий в нём нет.

## Перенести в другой проект

1. Скопируйте **всю папку** `metal-print-viewer` в проект, сохранив вложенные папки.
2. Импортируйте `createPrintViewer` из `viewer.js`.
3. Передайте контейнер с заданной высотой, ссылку на изображение и параметры панели.
4. При закрытии страницы или компонента вызовите `destroy()`.

Модуль — обычный JavaScript для браузера. React, сервер Metavista, ключи и установка npm-пакетов не требуются. Three.js и освещение лежат рядом с модулем; CDN не используется.

Минимальный пример, если этот HTML расположен рядом с папкой `metal-print-viewer`:

```html
<div id="print-preview" style="height:500px"></div>
<script type="module">
  import { createPrintViewer } from './metal-print-viewer/viewer.js';

  const viewer = await createPrintViewer(
    document.querySelector('#print-preview'),
    {
      image: './my-photo.jpg',
      widthCm: 30,
      heightCm: 40,
      size: 'M',
      mount: 'float',
      finish: 'gloss',
    }
  );

  await viewer.readyImage();
  // Позже: viewer.update({ mode: 'back' });
  // При удалении компонента: viewer.destroy();
</script>
```

Для разработчика или другого агента: [INTEGRATE.md](./INTEGRATE.md). Права на сторонние библиотеки и освещение: [LICENSES.txt](./LICENSES.txt).

## Условия работы

- Современный браузер с WebGL. Если WebGL недоступен, создание просмотра вернёт ошибку `webgl_unavailable`. В демо она обработана: показывается обычное изображение. Так же можно сделать в своём интерфейсе.
- Для внешних изображений сервер изображения должен разрешать CORS. Проще отдавать фото с того же сайта или использовать локальный `blob:` URL.
- Сохраните относительные пути `viewer.js`, `internal/`, `vendor/` и `assets/`. Демо и Markdown-файлы в рабочую страницу включать не нужно.
- В проектах с серверным рендерингом создавайте просмотр только в браузере после появления контейнера.
- Освещение и материал дают предпросмотр; точное совпадение с физической печатью и цветопробу модуль не обещает.

Модуль не содержит оплаты, аналитики, токенов и обращений к сайту Metavista.
